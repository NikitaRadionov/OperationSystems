Принятые имена файлов в текущей работе: - файлы с исходным кодом:               program<none/1/2>.c
                                        - скомпилированные исполняемые файлы:   executable<none/1/2>
                                        - выходные файлы:                       out_<num>.txt
                                        - входные файлы (из директории inputs): <num>.txt

Все файлы с исходным кодом (*.с) компилировать командой "gcc -o <имя скомпилированного исполняемого файла> <имя файла с исходным кодом (*.с)>"

Для заданий от 4 до 7 баллов разработаны bash-скрипты для быстрого запуска.

Формат запуска заданий со стоимостью 8 и 9 баллов: сначала запускается первый исполняемый файл, после чего запускается второй.

Формат запуска задания за 10 баллов: запускается только первый исполняемый файл (второй исполняемый файл вызывается из первого).

Общий формат запуска исполняемых файлов: <имя исполняемого файла> ../inputs/<номер входного файла>.txt out_<номер входного файла>.txt <параметр N> (номера входных файлов с 1 до 5)
